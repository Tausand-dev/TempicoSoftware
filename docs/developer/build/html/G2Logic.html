Orchestration layer for the g²(τ) HBT measurement tab.

Creates and manages a single pyqtgraph PlotWidget that displays the normalized second-order correlation function g²(τ) in real time. Instantiates and controls a WorkerThreadG2 during acquisition, and provides save (data + plot) functionality after the measurement finishes.

save_data()[source]

Save the current g²(τ) measurement to two text files.

Opens a format-selection dialog (txt / csv / dat) and writes:

  • ..._StartStopTimes: the raw (unbinned) stop times recorded during the acquisition, one row per detected event — the raw start-stop data behind the measurement.

  • ..._G2Curve: the analyzed data, i.e. the g²(τ) curve itself (τ in ns and the corresponding normalized g²(τ) value).

Both files share the same header with the measurement parameters (bin width, window, TDC mode, stop channel).

None

start_graphic()[source]

Start the g²(τ) acquisition.

Resets the curve, disables controls that must not be used during measurement, stops the connection-polling timer, notifies the main window, and launches the WorkerThreadG2. The number of stops requested per run is read directly from the selected stop channel’s current device configuration (getNumberOfStops()), so the measurement always matches what the Channels settings dialog shows — no internal default is silently substituted.

Returns:

None
